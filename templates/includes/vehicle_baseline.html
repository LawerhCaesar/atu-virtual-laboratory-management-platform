Common vehicle reference and model-specific assumptions

The platform uses the {{ vehicle_baseline.identity }} as its common vehicle reference. Generic educational illustrations should not be treated as verified GV70 scans or manufacturer models.

Reference values: {{ vehicle_baseline.mass_kg }} kg modelling mass; {{ vehicle_baseline.wheel_count }} wheels; {{ vehicle_baseline.tyre_size }} tyres; {{ vehicle_baseline.wheel_radius_m|floatformat:3 }} m wheel radius; {{ vehicle_baseline.wheelbase_m|floatformat:3 }} m wheelbase; {{ vehicle_baseline.length_m|floatformat:3 }} m length, {{ vehicle_baseline.width_m|floatformat:3 }} m width and {{ vehicle_baseline.height_m|floatformat:3 }} m height. The baseline centre-of-gravity height of {{ vehicle_baseline.cg_height_m|floatformat:3 }} m is an assumption.

{% if walkthrough_module.route == "core:brakelab" %}

BrakeLab retains its supplied model-specific defaults: 1,500 kg vehicle mass and 0.31 m wheel radius. Mass is adjustable; wheel radius is a fixed calibration in this model. Its numerical outputs therefore do not use the common baseline by default.

{% elif walkthrough_module.route == "core:wheel_slip" %}

Wheel-Slip retains its supplied model-specific defaults: 1,500 kg vehicle mass and 0.31 m wheel radius. Both are adjustable in the inputs. Its numerical outputs therefore do not use the common baseline by default.

{% elif walkthrough_module.route == "core:engine_live_data" %}

Engine Live Data uses imposed sensor values and does not model the common vehicle body or wheel dimensions. Its 3D and 2D mechanisms are generic educational illustrations.

{% elif walkthrough_module.route == "core:fuel_delivery" %}

The fuel simulation does not model vehicle geometry or mass. Its 3D fuel assembly is generic, not verified GV70 component geometry.

{% elif walkthrough_module.route == "core:battery_energy" %}

Battery Energy Management retains its supplied 96s24p equivalent pack: 345.6 V nominal, 100.8 Ah and 200 kg thermal mass. The stationary silhouette is illustrative; vehicle geometry, driving range and cell-level variation are not modelled.

{% elif walkthrough_module.route == "core:bless" %}

Bless retains the supplied passenger-van study: 3,004 kg converted kerb mass, 2,650 kg diesel kerb mass, 540 kg common payload and 0.35 m wheel radius. Its illustration is a generic van. GV70 dimensions are not substituted into this validated model.

{% elif walkthrough_module.route == "core:engine_generator" %}

Engine–Generator retains independent fuel and normalized component maps. Vehicle mass and geometry do not enter its equations. Its stationary silhouette is illustrative; external SOC is not a battery dynamics model.

{% elif walkthrough_module.route == "core:p2_hybrid" %}

P2 Hybrid uses independent torque, motor and battery parameters. No vehicle mass, wheel radius or body geometry enters its equations. Its power-flow illustration is a technical schematic, not a calibrated GV70 powertrain.

{% elif walkthrough_module.route == "core:micro_hybrid" %}

The stop-start calculation does not use a vehicle body, mass or wheel dimensions. Its car and traffic-light sequence is illustrative.

{% elif walkthrough_module.route == "core:steering_response" %}

Steering Response retains its supplied reference defaults: 1,500 kg base mass, 1.2 m CG-to-front distance and 1.6 m CG-to-rear distance (2.8 m wheelbase). The shared-baseline scenario explicitly applies 2,000 kg and 2.875 m, preserving the reference a:b split as an assumption. Inertia and cornering stiffness are independent model inputs, not verified GV70 measurements. The top-down car is an enlarged illustrative marker.

{% endif %}

Model-specific operating values and adjustable scenarios are described in each module. The baseline does not validate an individual model's equations or physical predictions.
