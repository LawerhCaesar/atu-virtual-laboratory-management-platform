    Equations and model boundaries

    Front slip αf = δ − β − ar/U; rear slip αr = −β + br/U. Axle forces are Fyf = Cfαf and Fyr = Crαr. Sideslip rate β̇ = (Fyf + Fyr)/(mU) − r; yaw acceleration ṙ = (aFyf − bFyr)/Iz.

    Heading rate ψ̇ = r; Ẋ = U cos(ψ + β); Ẏ = U sin(ψ + β). Lateral acceleration is (Fyf + Fyr)/m; turning radius is U/(|r| + 0.001). The epsilon is part of the reference equation, so straight-line radius is a large finite value.

    Zero initial states, constant longitudinal speed and linear axle tyres. Internal protections use at least 0.5 m/s and limit total mass to 100–50,000 kg, with warnings. Coarse output intervals in stiff cases use disclosed, fixed RK4 subdivisions; the reference case uses one step per output interval.

    No nonlinear tyre saturation, load transfer, steering-assist dynamics, roll, pitch, suspension, braking or stability control. This educational simulation is not road-safety approval.
