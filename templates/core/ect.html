Learning guide and reference evidence

The input sets coolant temperature. A first-order thermal model calculates sensor lag, then an NTC resistance equation and voltage divider feed the ADC. The ECU reconstructs temperature from that digital count.

Start with Default heating. At 20 seconds the coolant steps from 20 °C to 100 °C. Scrub to 23 seconds to inspect sensor lag, then to 120 seconds: expect 100 °C sensor temperature, about 174.380 Ω, 0.327243 V and ADC count 268.

Conversion error is ECU estimate minus sensor temperature, not sensor lag. At an ADC rail the finite estimate is a guarded fallback, explicitly invalid.

The supplied engine’s 37 checks are retained. The guide reports comparison with 12,001 Simulink samples; the independent CSV was not included, so that full native comparison has not been repeated here. Other presets are analytical and guard tests, not verified native traces.

Ideal educational sensor model; no combustion, coolant-flow rate, fan control, vehicle movement or production ECU calibration is implied.
