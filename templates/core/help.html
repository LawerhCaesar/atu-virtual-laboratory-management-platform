Help and support

Account access

Register as a Student or Lecturer. An Administrator must approve your registration and complete academic setup before you can sign in. Administrator accounts are not publicly registered.

If you forget your password, contact the authorised platform Administrator. Temporary passwords must be changed at first sign-in. Never send a password in a support request.

Students

Open an assigned practical task, read the instructions and deadline, then start an attempt. Save your response, record the approved demonstration run and upload the required evidence. Saving a draft does not submit it: use Submit attempt when ready.

Use only approved task resources. A disabled resource cannot be launched. If you receive correction feedback, start the permitted resubmission before the deadline. Grades and feedback become visible only after the Lecturer releases them.

Lecturers

Create tasks only within your assigned course offerings. Set questions, instructions, evidence requirements and a future deadline; attach approved resources and publish to enrolled Students. Review submitted evidence, request a permitted correction or save an assessment. Release results explicitly when ready.

Administrators

Use the dashboard for registration review, account access, course allocation, resource approvals, notices, support, reports and audit records. Disabling resources or suspending accounts retains historical records. Restoration requires fresh resource approval or an eligible account reactivation.

This platform supports educational management and approved demonstrations. It does not replace physical workshop training or validate automotive models.
