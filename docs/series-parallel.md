# Series–Parallel Hybrid supervisory control

Route `/virtual-lab/hev/series-parallel-hybrid/`, under HEV. Existing active-role authentication applies. Source specifications are preserved in `docs/reference/series-parallel/`; the document titled AGENTS.md was treated as an uploaded module specification, not installed as repository-wide instructions.

The deterministic core, `static/js/series-parallel/engine.mjs`, implements the supplied road loads, PI driver, exact scenario profiles, priority selector, dwell/transition timers, eight mode allocations and fuel/SOC/motion updates. Configuration is centralized in DEFAULTS and validated before running. It exposes createSimulation, reset, step, current frame, serialized state, runScenario and CSV. The browser adapter computes the short run locally and replays fixed-grid frames; presentation time never integrates physics. Maximum workload is bounded to 30000 updates. UI parameter edits apply atomically; a failed validation retains the prior completed run. No database migration, backend request per step or dependency was added.

The model follows the supplied sample convention: the call at t=0 advances using the fallback 0.1 s interval. A default run contains 301 updated frames including t=0 and t=30. This is necessary to match the supplied golden sequence and should not be confused with a pre-update t=0 observation. Summary interval integrals use frames after the opening frame. Raw cumulative fuel and recovered energy retain the core's exact convention. SOC clamps to 0.30–0.80; socHigh is normalized and retained but does not participate in the supplied selector. No invented hysteresis was added.

All nine transitions match exactly: 0.4 electric, 4.4 series, 7.4 combined, 10.5 mechanical, 13.8 combined, 17.5 mechanical, 18 regenerative, 23 charging, 29 regenerative. Final output is 69.598724 km/h, SOC 0.602785995, fuel 0.077059578 L and recovered energy 0.082687959 kWh. The core also checks formula anchors, all four scenarios, bounds, finite values and clutch state.

Sign conventions: positive wheel power propels, negative brakes; positive battery power discharges, negative charges. Recovered energy counts every negative battery contribution, including engine charging. Unmet power is positive propulsion shortfall and excludes braking shortfall. The baseline permits an instantaneous overall-efficiency cap of 120%; do not interpret it as experimentally measured efficiency. Scenario 1 intentionally lowers only control SOC from 23–29 s, and is visibly labelled verification rather than a fuel-economy cycle.
